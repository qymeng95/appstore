# SillyTavern

SillyTavern 是一个开源的AI聊天前端界面，支持多种AI语言模型的接入。

## 主要功能：

- **多模型支持**：支持接入多种AI语言模型，包括OpenAI、Claude等
- **角色定制**：支持创建和导入自定义角色，可以设置角色个性和行为
- **对话管理**：提供完整的对话历史记录管理功能
- **插件系统**：支持插件扩展，可以增强功能
- **用户界面**：直观友好的用户界面，支持暗色/亮色主题
- **数据备份**：支持对话和设置的导入导出
- **多语言支持**：支持多种界面语言
- **安全性**：本地运行，数据存储在用户端

## 使用说明

1. 首次启动后，访问系统分配的端口进入管理界面
2. 在设置中配置AI模型的API密钥
3. 开始创建角色或导入现有角色进行对话

## 注意事项

- 请妥善保管API密钥
- 建议定期备份重要的对话数据
- 使用时需确保有稳定的网络连接
